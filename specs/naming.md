This document visualizes the naming conventions and resource topology for the HyperShell multi-tenant GitOps architecture.

## 2. Resource Naming Table

| Name | Kind | Scope | Desc |
| :--- | :--- | :--- | :--- |
| `cnpg-system`, `keycloak-system` | Namespace | Shared Platform | Singleton namespaces shared across all instances. |
| `cnpg-controller-manager`, `keycloak` | Deployment | Shared Platform | Singleton deployments inside shared namespaces. |
| `keycloak-db` | Cluster (CNPG) | Shared Platform | Database for the singleton Keycloak instance. |
| `hypershell-controller-<instance>` | ClusterRole | Cluster-Scoped RBAC | Suffixed to prevent multi-tenant overwrites (e.g., `-hyp0`). |
| `hypershell-controller-<instance>` | ClusterRoleBinding | Cluster-Scoped RBAC | Links the ClusterRole to the instance's ServiceAccount. |
| `hypershell-controller-scc-bind-<instance>` | SCC Bindings | Cluster-Scoped RBAC | Grants OpenShift SCC access for the specific instance. |
| `<instance>` (e.g., `hyp0`, `hyp1`) | Namespace | Control Plane Instance | Isolates the control plane. |
| `hypershell-controller-<instance>` | ServiceAccount | Control Plane Instance | Runs the controller. Subject of the suffixed ClusterRoleBinding. |
| `hypershell-db-<instance>` | Cluster (CNPG) | Control Plane Instance | Base DB cluster name explicitly suffixed for visual clarity. |
| `hypershell-db-<instance>-app` | Secret | Control Plane Instance | Auto-generated by CNPG. Hardcoded in volume mounts. |
| `hypershell-api-server-<instance>`, `hypershell-controller-<instance>`... | Deployment | Control Plane Instance | Core control plane components explicitly suffixed. |
| `openshell-<hash>` | Namespace | Tenant Gateways | Dynamically generated by the controller at runtime. |
| `openshell-db-<hash>` | Cluster (CNPG) | Tenant Gateways | Isolated tenant database explicitly suffixed to the tenant hash. |
| `openshell-gateway-<hash>` | Deployment | Tenant Gateways | The gateway application deployment explicitly suffixed. |
| `openshell-gateway-<hash>` | ServiceAccount | Tenant Gateways | Runs the gateway, explicitly suffixed. |
| `openshell-gateway-*-<hash>` | NetworkPolicy | Tenant Gateways | Tenant-specific network isolation policies explicitly suffixed. |
